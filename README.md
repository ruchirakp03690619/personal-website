# Personal Website — GitHub Pages

A responsive personal portfolio with a nature-inspired visual style, research sections, project cards, a photo journal, and rotating inspirational quotes.

## 1. Personalise the content before publishing

Open `index.html` and replace:
- `YOUR NAME` / `Your Name` with your preferred display name.
- `your.email@example.com` with the email address you want to publish.
- Update the academic profile, research interests, projects, and social links.
- Replace the sample gallery and project images with your own images if desired.

The current image backgrounds are remotely hosted sample photographs. An internet connection is required to display them. You can replace their image URLs in `styles.css`.

## 2. Upload to GitHub

1. Open your repository: `https://github.com/myusername/personal-website`
2. Select **Add file → Upload files**.
3. Upload `index.html`, `styles.css`, `script.js`, and `README.md` (and the `assets` folder if you add your own images).
4. Select **Commit changes**.

## 3. Enable GitHub Pages

1. In the repository, open **Settings**.
2. Select **Pages** in the left sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose branch **main** and folder **/(root)**.
5. Select **Save**.

After GitHub finishes publishing, your website should be available at:

https://myusername.github.io/personal-website/

It may take a few minutes for the first deployment. If it does not appear immediately, wait and refresh.

## 4. Updating later

Edit the files directly on GitHub or upload revised files. Each commit to the `main` branch will trigger a new deployment.

## Notes

- This is a static website: no server or paid hosting is required.
- Do not publish private information, personal phone numbers, or documents you do not want public.
- The email and social links are placeholders until you replace them.
- The website uses Google Fonts and externally hosted sample images.
